# Druid Wild Shape 2024 - веб-конструктор

Статическое веб-приложение для D&D 2024.

## Что умеет

- выбор уровня друида и автоматический контроль максимального ПО/числа известных форм;
- библиотека зверей с **полной карточкой прямо на странице**, без отдельной кнопки «Подробнее»;
- добавление форм в 6/8/10 и т.д. слотов в зависимости от уровня;
- создание собственных существ;
- сохранение своих существ в браузере;
- экспорт/импорт данных JSON;
- PDF с выбранными формами - **3 полные карточки на странице A4**;
- печать через браузер.

## Запуск

Открой `index.html` в современном браузере. Для PDF требуются CDN-версии `html2canvas` и `jsPDF`, поэтому при первом запуске нужен доступ к интернету.

Источник встроенных данных: D&D Vault / PHB 2024:
https://dndvault.ru/book-phb-2024/chapter-app-b-creatures
